# Linking from a course site

The app is a public web page. Link to it from any page, assignment or module in your course site. No login, embedding or plug-in is needed.

Main link: https://wangy113.github.io/early-viking-simulation/

## Suggested link text

> Open the Gokstad Ship Explorer (opens in a new tab)

Set the link to open in a new tab, so students keep their course page open beside the scene.

## Links straight to a place

Add these to the end of the main link to skip the welcome screen:

| Add this | Goes to |
|---|---|
| `#stop=1` to `#stop=12` | That stop, with its text open |
| `#deck` | Standing on the deck |
| `#overview` | A bird's-eye view of the ship and camp |
| `#deck&sail` | On deck with the sail raised |
| `?quality=low` | The lightest graphics, for older laptops and Chromebooks |

Example: https://wangy113.github.io/early-viking-simulation/#stop=5 opens the steering board.

## If the scene is slow

The Quality button in the menu switches between Low, Medium and High, and the browser remembers the choice. Students can also use the Text version, which has every stop's content without the 3D scene.
