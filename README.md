# Gokstad Ship Explorer

An interactive 3D walk around a reconstruction of the Gokstad Viking ship, built about 890 and found near Sandefjord, Norway, in 1880. It is made for online students and is meant to be embedded in Canvas.

Students visit 12 numbered stops. Each stop is tagged to show what was found with the ship, what is known from other finds, and what is a reconstruction.

Live site: https://wangy113.github.io/early-viking-simulation/

Useful links:
- `#stop=N` opens stop N directly (1 to 12)
- `#deck` starts on board
- `#sail` starts with the sail raised

Project notes and the progress ledger are in `docs/HANDOFF.md`.
